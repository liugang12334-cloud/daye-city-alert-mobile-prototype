# 大冶市城市智能预警平台 · 移动端 Demo 原型

面向大冶市应急管理局「城市安全预警平台」移动端的可交互 Demo，用于业务流程演示与需求评审。
纯静态单文件 HTML，内联 CSS/JS，双击即可用浏览器打开，不依赖后端与构建工具。

## 在线预览

用浏览器打开 `07-移动端HTML原型.html`（窗口宽度 ≥1060px 时，右侧会自动出现「页面跳转关系·全局视图」平铺面板）。
本地无需服务：`open 07-移动端HTML原型.html`。

## 业务闭环

巡查上报/六源信号 → 值守研判（5 分钟）→ 生成火情工单 → 分级派发（黄/橙/红）
→ 乡镇值班室 5 分钟签收 → 到场处置（15/30/60 分钟）→ 每 30 分钟进展反馈
→ 扑灭后 30 分钟结果报告 → 市局核查（通过/退回）→ 办结销号归档

## 三套分级（严禁混用）

- 事前 · 森林火险预警：蓝 / 黄 / 橙 / 红
- 事中 · 火情工单：黄 / 橙 / 红
- 成灾 · 应急响应：Ⅳ / Ⅲ / Ⅱ / Ⅰ
